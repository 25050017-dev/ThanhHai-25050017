ĐI CÙNG NHAU - WEBSITE CỘNG ĐỒNG YÊU DU LỊCH

Cách chạy:
1. Giải nén thư mục.
2. Mở thư mục cong_dong_du_lich bằng Visual Studio Code.
3. Mở index.html bằng trình duyệt hoặc dùng tiện ích Live Server.
4. Website sử dụng ảnh minh họa từ Unsplash qua Internet; cần kết nối mạng để hiển thị ảnh.
